This section records the events that I actually participated in during the AWS First Cloud AI Journey internship. Event 4 is kept as a placeholder in the report structure, but it is clearly marked as not participated and is not used as attendance evidence.

### [Event 1](4.1-event1/)

&emsp;**Event Name:** Cloud Architect Game Show

&emsp;**Date & Time:** June 20, 2026

&emsp;**Location:** 26th Floor, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City

&emsp;**Role:** Attendee

&emsp;**Main Content & Activities:**
* **AWS Architecture Quiz Competition:** Followed a head-to-head game show with 8 teams, 5 members per team and 4 quarterfinal matches.
* **Question Structure:** Each match used 10 questions, with harder AWS and solution architecture questions appearing in later rounds.
* **Knockout Format:** Winning teams advanced from quarterfinals to semifinals; the final was postponed because the event time was limited.
* **Special Skills:** Observed how teams used Minimum Risk and Hope Star to manage scoring risk during uncertain or high-confidence answers.
* **Memorable Team:** Team Ngu Dai Hiep reached the final and showed strong teamwork under pressure.

&emsp;**Outcomes & Values Gained:**
* Reviewed AWS fundamentals, advanced services and certification-style architecture reasoning in a competitive format.
* Learned to read scenario constraints carefully, compare service trade-offs and communicate faster in team-based decision making.

### [Event 2](4.2-event2/)

&emsp;**Event Name:** AWS Tech Meetup & Community Knowledge Sharing

&emsp;**Date & Time:** July 11, 2026

&emsp;**Location:** 26th Floor, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City

&emsp;**Role:** Attendee

&emsp;**Main Content & Activities:**
* **SLA & Monitoring:** Discussed why healthy infrastructure does not always equal healthy user experience and how to monitor business actions with CloudWatch custom metrics.
* **AWS Certified Cloud Practitioner CLF-C02:** Reviewed exam domains, Shared Responsibility Model, keyword mapping and mock-test review strategy.
* **AWS Security Agent:** Explored AI-assisted DevSecOps for design review, code review and automated pentesting with verifiable findings.
* **Alerting Flow:** Connected CloudWatch Alarm and SNS Topic to notify technical teams before customers experience broad impact.
* **Community Exchange:** Learned from infrastructure and DevSecOps practitioners in the AWS First Cloud AI Journey community.

&emsp;**Outcomes & Values Gained:**
* Understood that monitoring should measure real user journeys, not only CPU, RAM or server health.
* Built a clearer learning plan for CLF-C02 and saw how AI agents can support Shift-Left Security in modern cloud projects.

### [Event 3](4.3-event3/)

&emsp;**Event Name:** Agent Forge - Deepdive Day 1

&emsp;**Date & Time:** August 1, 2026, 09:00 - 12:00

&emsp;**Location:** Bitexco Financial Tower, Ho Chi Minh City

&emsp;**Role:** Attendee

&emsp;**Speakers:**
* **Nghia Tran:** Agentic SA, speaker for the Amazon Bedrock AgentCore theory session.
* **Anh Pham:** Cloud Consultant at G-AsiaPacific VietNam, speaker for the cloud implementation and hands-on perspective.

&emsp;**Main Content & Activities:**
* **Amazon Bedrock AgentCore Overview:** Learned the role of AgentCore in building and operating agentic applications on AWS.
* **Runtime, Gateway and Identity:** Reviewed the core building blocks for executing agents, connecting external tools and controlling user identity.
* **Hands-on Lab:** Followed the flow to deploy a basic agent, connect external tools and Knowledge Bases, build a Web UI and integrate Amazon Cognito authentication.
* **Agent Architecture Discussion:** Understood why AI agents should be designed with security, identity, tool boundaries and operational control from the beginning.

&emsp;**Outcomes & Values Gained:**
* Gained a clearer view of how Amazon Bedrock AgentCore supports structured agent development beyond simple prompt-based chatbot prototypes.
* Learned that practical agent applications require runtime design, controlled tool access, Knowledge Base governance and authentication through services such as Amazon Cognito.
